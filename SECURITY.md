# Security Policy

## Scope

This repository contains documentation and examples for an AI skill bundle. It does not include NinjaTrader credentials, provider credentials, trading accounts, or a NinjaTrader runtime.

## Reporting A Vulnerability

Do not disclose suspected vulnerabilities in a public issue.

For a private GitHub repository, use GitHub's private vulnerability reporting or security advisory workflow when it is enabled. If that workflow is unavailable, contact a repository administrator through the repository's private GitHub access controls and include:

- A concise description of the issue and its potential impact.
- The affected file, version, or commit.
- Reproduction steps or a minimal proof of concept, with secrets and personal data removed.
- Any suggested mitigation.

Please allow maintainers reasonable time to investigate before making details public.

## Sensitive Information

Never commit tokens, passwords, private keys, provider credentials, account details, personal data, or proprietary source material. If sensitive information is committed, revoke or rotate it immediately and report the incident privately.
